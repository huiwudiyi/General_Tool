# 多模态工具功能描述

## 1、背景
query调用多模态工具召回的结果文本数据和截图，根据召回的数据生成多模态工具的功能描述
框架：python、langgraph、harness、sqlite等

## 2、功能需求
### 2.1 输入数据
提供excel数据，格式如下：
- query: 用户输入的query
- srcid: 工具的id
- label_data：用户query调用多模态之后返回的文本数据	
- 截图：用户query调用多模态之后返回的截图数据
